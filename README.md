# Fridge Foodie

Hola, quiero crear una aplicación que sea como una nevera virtual. Quiero que la persona cuando haga su compra pueda poner todo lo que ha comprado y se guarde en su nevera virtual, y mi aplicación le dé ideas de recetas con lo que tiene en la nevera. Así será una aplicación fitness. Ayúdame y crea toda la estructura de la aplicación.
