# Fridge Foodie

This project was developed during the first running Hackathon Barcelona. 
This project was built with [Lovable](https://lovable.dev).

**Live app**: https://fit-fridge.lovable.app

The app represents your virtual fridge. 
Every time a user goes to the supermarket, he can scan all the purchased items, so the virtual fridge keeps a count of what he has on his fridge. 
With this information, the app shows the customer which recipes can be done with what the customer has in his fridge. It also sends a notification if something is going to expire.

Other functionalities:
- Organizing your shopping: You can tell the app what budget you have and in which supermarket you want to go, and the app makes a weekly plan of your meals, and a list of what you have to buy to do them.
